# Realistic 3D scroll homepage: exploration (25 Nov 2026)

Branch `explore/3d-homepage`. A separate exploration the user asked for: it does **not** follow the site's
CLAUDE.md rules and is not for `main` unless the user decides so. Durable plan and progress log: a session on the
user's Mac or in the cloud resumes from this file and the pushed branch.

## Decisions (user, 25 Nov 2026)

- Concept **A, "One building, every door"**, made **realistic**, seen **through the visitor's eyes** (the camera is
  the visitor, so no 3D people or cars).
- Devices modelled in **Blender by script** (`3d/`), at the real products' proportions from AIMS's photos.
- **All rendering and baking runs on the user's Mac** (MacBook Air M1, 8 GB, Metal), never in the cloud session.
  The cloud session only writes scripts and builds scenes without rendering.
- Model: Opus 5.5 at high effort for modelling, lighting and the 3D web code; Sonnet subagents for routine jobs.

## Pipeline

1. Blender scripts model devices and spaces (`3d/aims3d/*.py`), materials as nodes (`materials.py`).
2. On the Mac: EEVEE previews, Cycles stills, Cycles light baking; camera path and device motion as Blender
   animation; export glTF (meshopt/Draco, KTX2).
3. Web: React Three Fiber + drei + GSAP ScrollTrigger + Lenis, postprocessing bloom on LEDs and scan beams; the
   BioTime monitor is live HTML; one photoreal still per chapter for first paint, slow phones and reduced motion.
